# Dark Destiny [![License](https://img.shields.io/github/license/bDekaru/ClassicACE?style=plastic)](https://github.com/bDekaru/ClassicACE/blob/master/LICENSE)

**Dark Destiny is an Asheron's Call Emulator based on ClassicACE, and thus also ACEmulator.**
Gameplay is based on the Infiltration ruleset in ClassicACE, though the others (CustomDM, EoR) are included for completeness.

**Required Data Files:**
